CatLayer v1.2.1 편집 기능 설명서
================================

[기본 상태]
- 고정: 오버레이 클릭 통과
- 편집: 이동/크기 조절/그룹/회전/반전/자르기/정밀 이동 사용
- F8 기본값으로 고정 ↔ 편집 전환

[선택 / 이동]
- Shift+클릭: 다중 선택
- 목록 Ctrl+클릭: 다중 선택
- 방향키: 1px 이동
- Shift+방향키: 10px 이동
- 우클릭 드래그: 오버레이 이동
- Shift를 누른 채 이동하면 배치 자석을 일시적으로 무시

[크기 / 자르기]
- 선택 테두리/핸들 드래그: 크기 조절
- 이미지에서 Shift+크기 조절: 이미지 자르기
- Ctrl+휠: 그룹 또는 항목 확대/축소
- Ctrl+Shift+휠: 그룹 여부와 상관없이 개별 확대/축소

[회전 / 반전]
- Ctrl+좌클릭 드래그: 자유 회전
- Q / E: -1° / +1°
- Shift+Q / Shift+E: -10° / +10°
- H / V: 좌우 / 상하 반전
- R: 각도만 0°
- Shift+R: 회전/반전 전체 초기화

[그룹]
- Ctrl+G: 그룹화/그룹해제 토글
- Ctrl+Shift+G: 그룹 해제
- 그룹을 .catlayergroup으로 저장/불러오기 가능

[빠른 숨김 / 표시]
- F9: 클릭한 오버레이 우선, 없으면 목록 위에서부터 하나씩 숨김
- Shift+F9: 최근 빠른 숨김부터 하나씩 복원
- F11: 전체 숨김 ↔ 전체 표시
- 리모컨에서도 빠른 숨김 / 숨김 취소 / 선택 표시 사용 가능

[웹 오버레이]
메뉴 > 설정 > 웹 조작 방식:
- 더블클릭: 웹 더블클릭 후 조작
- 원클릭: 단순 클릭 후 조작, 드래그 이동은 별도로 인식
- 통합: 일반 오버레이 편집과 웹 직접 조작을 동시에 사용

F10은 웹 조작 모드 직접 전환 기본키입니다.
웹 조작 모드에서 Ctrl+휠은 웹페이지 확대/축소입니다.
통합 방식에서 웹 위치/크기는 바깥 선택 테두리를 사용합니다.

[프로그램 자석]
- 다른 프로그램 창 바깥/안쪽 가장자리 모두 부착 가능
- 대상 창 이동/크기 변경을 따라감
- 설정 > 프로그램 자석 감도... : 0~100px, 기본 36px
- 0px: 자동 프로그램 자석 끄기
- 우클릭 메뉴의 수동 프로그램 자석은 별도 사용 가능

[배치 자석]
- 화면 가장자리/중앙 및 다른 오버레이 선에 자동 정렬
- 설정 > 배치 자석 감도... : 0~30px, 기본 8px
- 0px: 끄기

[리모컨]
- 메인/오버레이 우클릭/트레이 우클릭에서 열기
- 오버레이 목록 선택
- 편집/고정, 전체 표시/숨김, 빠른 숨김, 숨김 취소,
  선택 표시, 웹 새로고침, 프리셋, 그룹 불러오기
- 파일/URL 드래그앤드롭 지원
- 창 크기 조절 가능

[삭제 / 복사 / 실행 취소]
- Delete: 선택 오버레이 삭제
- Ctrl+C: 선택 오버레이 복사 (OBS 제외)
- Ctrl+V: 정적 이미지 붙여넣기
- Ctrl+Z: 실행 취소

웹페이지의 실제 텍스트 입력칸에 포커스가 있으면 Delete/Ctrl+C/Ctrl+V 같은 입력은 웹페이지 동작을 우선합니다.

[사용자 지정 단축키]
메뉴 > 설정 > 사용자 지정 단축키에서 전역 단축키와 편집 단축키를 구역별로 설정할 수 있습니다.
기본 영역 캡처 키는 Ctrl+Shift+X입니다.
리모컨 열기 / 선택 웹 새로고침 / 프리셋 불러오기 / 그룹 불러오기는 기본 미지정입니다.
