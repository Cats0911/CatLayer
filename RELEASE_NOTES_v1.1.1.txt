CatLayer v1.1.1 릴리스 노트
==========================

주요 변경
- WebView2 기반 웹 오버레이와 CatLayerWeb 위젯 지원
- 웹 조작 방식을 더블클릭 / 원클릭 / 통합 중 선택 가능
- .catlayergroup 그룹 공유 및 WebP 지원
- 프로그램 창 안쪽/바깥쪽 자석 및 감도 설정 추가
- 프로그램 자석 추적/부착 안정성 개선
- 리모컨 추가: 오버레이 목록, 빠른 숨김/복원, 선택 표시, 웹 새로고침, 프리셋/그룹 불러오기
- 리모컨 파일/URL 드래그앤드롭 및 창 크기 조절 지원
- 빠른 숨김(F9), 빠른 표시(Shift+F9), 전체 표시/숨김(F11) 분리
- 우클릭 드래그 오버레이 이동 지원
- 영역 캡처 기본키를 F1에서 Ctrl+Shift+X로 변경
- 리모컨/웹 새로고침/프리셋/그룹 불러오기 전역 단축키 사용자 지정 추가
- 사용자 지정 단축키 설정 창을 CatLayer 다크 UI로 개편
- Delete 키 처리, 웹 입력 포커스, 오버레이 선택/이동 관련 안정성 개선

설치
- ZIP 전체를 압축 해제한 뒤 INSTALL.bat 실행
- 첫 설치 시 필요한 WebView2 SDK가 없으면 Microsoft NuGet에서 고정 버전을 한 번 내려받습니다.
- 웹 오버레이 사용에는 Microsoft Edge WebView2 Runtime이 필요합니다.

주의
- 기존 설정/프리셋은 %LOCALAPPDATA%\CatLayer 아래에 유지됩니다.
- 웹 로그인/쿠키/캐시는 프리셋이나 CatLayerWeb 파일에 포함되지 않습니다.
