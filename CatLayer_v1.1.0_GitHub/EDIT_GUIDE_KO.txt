CatLayer v1.0.5 편집 기능 설명서
====================================

1. 편집 상태
------------
CatLayer v1.0.5부터 고정 모드와 편집 모드 두 단계만 사용합니다.
기존 세부 편집 모드는 제거되었고 회전/반전/정밀 이동/그룹/휠 확대 기능이 편집 모드에 통합되었습니다.

[고정 모드]
- 오버레이 클릭 통과
- 편집 조작 비활성화

[편집 모드]
- 이동 / 크기 조절
- Shift+클릭 다중 선택
- 그룹 만들기/해제
- Ctrl+드래그 자유 회전
- 좌우/상하 반전
- 방향키 정밀 이동
- Ctrl+휠 확대/축소
- 이미지 Shift+크기 조절 자르기

선택된 오버레이만 편집 테두리가 표시됩니다.
다른 프로그램을 클릭하면 테두리는 숨겨지지만 선택 상태는 유지됩니다.

2. 이미지 자르기
----------------
- 이미지의 테두리/모서리에서 Shift를 누른 채 크기 조절 방향으로 드래그합니다.
- 일반 크기 조절과 달리 이미지 내용이 잘립니다.
- 이미지 몸통에서 Shift+클릭하면 기존처럼 다중 선택으로 동작합니다.
- 잘린 상태는 config, 프리셋 V6, Undo, 오버레이 복사에 유지됩니다.

3. 배치 자석
------------
- 오버레이 이동 시 화면 가장자리/중앙과 다른 오버레이의 선에 가까워지면 자동으로 붙습니다.
- 설정 > 배치 자석 감도... 에서 0~30px 조절
- 기본 8px
- 0px = 끄기
- 그룹을 이동할 때 같은 그룹 구성원끼리는 자석 기준으로 사용하지 않습니다.

4. 회전 / 반전
---------------
- Ctrl+좌클릭 드래그: 자유 회전
- Q / E: -1° / +1°
- Shift+Q / Shift+E: -10° / +10°
- H / V: 좌우 / 상하 반전
- R: 각도만 0° (반전 유지)
- Shift+R: 각도 + 좌우/상하 반전 전체 초기화

[이미지 우클릭 빠른 변형]
- 좌우 반전: 해당 이미지의 좌우 반전 상태를 전환
- 상하 반전: 해당 이미지의 상하 반전 상태를 전환
- 각도 초기화 (반전 유지): 회전 각도만 0°로 만들고 좌우/상하 반전 상태는 유지
- 회전/반전 전체 초기화: 회전 각도 0° + 좌우/상하 반전을 모두 해제
- 각 작업은 Undo(Ctrl+Z)로 되돌릴 수 있습니다.

회전 자석:
- Ctrl+드래그 자유 회전에서 0/90/180/270°에 적용
- 설정 > 회전 자석 감도... 에서 0~15°
- 기본 5°, 0° = 끄기

5. 확대 / 축소
---------------
- Ctrl+휠: 그룹이면 그룹 전체 비례 확대/축소, 일반 항목이면 해당 항목 확대/축소
- Ctrl+Shift+휠: 그룹 여부와 무관하게 마우스가 올라간 항목 하나만 확대/축소
- 설정 > 확대/축소 비율... 에서 1~90%, 기본 10%

6. 선택 / 그룹
---------------
- 화면: Shift+클릭 다중 선택
- 목록: Ctrl+클릭 다중 선택
- Ctrl+G: 그룹화/그룹해제 토글
- Ctrl+Shift+G: 그룹 해제
- 그룹 이동 시 잠기지 않은 구성원이 함께 이동

7. 복사 / 삭제
---------------
- Ctrl+C: 선택된 오버레이를 즉시 복제
- 목록 우클릭 > 복사도 동일
- OBS는 하나만 사용할 수 있으므로 복사에서 제외
- 그룹을 여러 개 함께 복사하면 복사본은 새 그룹 ID를 사용
- Delete: 선택 오버레이 삭제
- Ctrl+Z: 실행 취소

8. 영역 캡처
------------
- F1 기본값 또는 메인 화면 영역 캡처 버튼
- 원하는 화면 영역을 드래그하면 해당 부분만 PNG 오버레이로 생성
- ESC 취소
- 멀티모니터 지원
- F1은 설정 > 사용자 지정 단축키에서 변경 가능

9. 화면 밖 오버레이 복구
------------------------
- 실행 시 현재 모니터 영역에서 벗어난 오버레이를 자동 복구합니다.
- 실행 중 디스플레이 구성이 바뀐 경우에도 자동 복구합니다.

10. 기본 단축키
---------------
F1 : 영역 캡처
F8 : 고정 ↔ 편집
F9 : 전체 표시 / 숨김
Ctrl+C : 오버레이 복사
Ctrl+V : 정적 이미지 붙여넣기
Ctrl+G : 그룹화/그룹해제
Ctrl+Shift+G : 그룹 해제
Q / E : 회전 -1° / +1°
Shift+Q / Shift+E : 회전 -10° / +10°
H / V : 좌우 / 상하 반전
R : 각도 초기화
Shift+R : 회전/반전 전체 초기화
방향키 : 1px 이동
Shift+방향키 : 10px 이동
Delete : 삭제
Ctrl+Z : 실행 취소

Ctrl+C / Ctrl+V는 CatLayer 예약키입니다.
F1/F8/F9 및 나머지 편집 동작 키는 사용자 지정 단축키 설정에서 변경할 수 있습니다.

11. 웹 오버레이
----------------
- 메인 화면 > 웹에서 HTTP/HTTPS 주소를 입력해 추가합니다.
- 편집 모드에서 웹페이지 안쪽을 클릭하면 일반 브라우저처럼 직접 조작할 수 있습니다.
- 웹 오버레이 자체 이동은 파란 선택 테두리를 드래그합니다.
- 우하단 사각형을 드래그하면 크기를 조절합니다.
- Shift를 누른 채 테두리를 이동하면 배치 자석을 일시적으로 무시합니다.
- 웹페이지가 키보드 포커스를 가진 동안 Ctrl+C/Ctrl+V 같은 일반 웹 입력은 웹페이지에 전달됩니다.
- 웹 투명도는 현재 지원하지 않으며 100%로 고정합니다.
- 로그인/쿠키/캐시는 %LOCALAPPDATA%\CatLayer\WebData 에 저장됩니다.

12. 프리셋 호환
----------------
- 웹 오버레이가 없으면 LIGHTOVERLAY_PRESET_V6으로 저장합니다.
- 웹 오버레이가 포함되면 LIGHTOVERLAY_PRESET_V7으로 저장합니다.
- 기존 V1/V2/V3/V4/V5/V6 프리셋 불러오기 지원 유지
- WebData의 로그인/쿠키/캐시는 프리셋에 포함하지 않습니다.

OBS Program 및 웹 오버레이는 자유 회전/반전을 지원하지 않습니다.


웹 오버레이 조작
- 기본 F10으로 웹 조작 모드를 켜고 끕니다.
- 웹 조작 모드에서는 다른 CatLayer 편집 동작이 비활성화되고 웹페이지 조작만 가능합니다.
- 편집 모드에서는 웹페이지 자체 대신 오버레이 테두리를 이용해 위치와 크기를 편집합니다.
- 웹 조작 모드에서 Ctrl+마우스 휠은 웹페이지 자체 확대/축소입니다.
- 웹 오버레이 우클릭 메뉴에서 투명도와 커스텀 CSS를 설정할 수 있습니다.

[그룹 파일 저장 / 불러오기 - v1.1.0 개발 기능]
1. 기존 그룹의 항목 하나를 선택하거나, Ctrl로 2개 이상 항목을 선택합니다.
2. 목록 우클릭 -> '그룹 파일로 저장...'을 선택하면 .catlayergroup 파일로 저장됩니다.
3. '그룹 파일 불러오기...'를 선택하거나 파일을 CatLayer에 드래그하면 기존 오버레이를 유지한 채 새 그룹으로 추가됩니다.
4. .catlayergroup 파일에는 사용한 이미지/GIF와 타이머 알람 파일도 포함되어 다른 PC로 공유할 수 있습니다.
5. 설치판에서는 .catlayergroup 파일 더블클릭으로도 불러올 수 있습니다.

[WebP 이미지]
- 이미지 / GIF 추가와 파일 드래그에서 .webp 확장자를 인식합니다.
- Windows 이미지 디코더가 읽을 수 없는 특수 WebP 파일은 경고를 표시합니다.
