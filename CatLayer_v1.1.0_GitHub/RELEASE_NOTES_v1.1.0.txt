CatLayer v1.1.0 Release Notes

주요 추가/변경
- WebView2 기반 웹 오버레이 기능 확장
- 편집 모드 웹 더블클릭 직접 조작
- F10 전체 웹 조작 모드 유지
- ESC로 웹 조작 모드 종료
- 웹 투명도, 커스텀 CSS, 페이지 줌
- 로컬 HTML 및 .catlayerweb 패키지 지원
- 로컬 웹 리소스 보안 강화
- 신뢰된 로컬 웹젯용 제한 resize API
- 기본 웹젯 5종: 메모장, 그림판, 미니계산기, 체크리스트, 타이머보드
- .catlayergroup 그룹 공유 기능
- WebP 이미지 지원
- GitHub Releases 기반 자동 업데이트
- 웹 크기 조절 후 투명 배경이 검게 남는 현상 보정
- CPU/RAM 및 반복 UI/설정 저장 작업 최적화

기존 기능과 프리셋 호환은 최대한 유지합니다.
