CatLayer GitHub 자동 업데이트 Release 준비

Repository: https://github.com/Cats0911/CatLayer

1. 새 버전의 INSTALL.bat를 실행해서 설치본을 갱신합니다.
2. PowerShell에서 다음 파일을 실행합니다.
   tools\Make-Update-Package.ps1

   기본 설치 위치인 %LOCALAPPDATA%\CatLayer\App 을 읽어서 다음 파일을 만듭니다.
   - CatLayer_v<버전>_update.zip
   - SHA256.txt

3. GitHub > CatLayer > Releases에서 해당 버전의 정식 Release를 만듭니다.
   자동 업데이트는 Pre-release와 Draft를 대상으로 하지 않습니다.

4. Release Assets에 반드시 두 파일을 같이 올립니다.
   - CatLayer_v<버전>_update.zip
   - SHA256.txt

5. CatLayer는 GitHub Releases API의 최신 정식 Release를 확인합니다.
   새 버전이 있으면 사용자에게 먼저 묻고, 승인한 경우에만 다운로드합니다.
   SHA-256 검증이 실패하면 업데이트를 적용하지 않습니다.

주의:
- GitHub가 자동으로 만드는 Source code (zip) / Source code (tar.gz)는 자동 업데이트 파일이 아닙니다.
- 프로그램 안에는 GitHub 토큰이나 비밀번호를 넣지 않습니다.
