CatLayer v1.2.0 업데이트

주요 변경
- 새 컴팩트 메인 화면과 우클릭/톱니 메뉴 적용
- Chromium/Firefox 브라우저 이미지 드래그 처리 강화
- Pinterest 이미지 드래그 및 대표 이미지 추출 개선
- 이미지 자동 최적화 기능 추가 (기본 ON, 원본 파일은 변경하지 않음)
- GIF 재생/일시정지 및 프레임 이동 기능 추가
- 비정상 종료 자동 저장 및 복구 기능 추가
- 그룹과 별개의 부모/자식 Hierarchy 기능 추가
- 자동 정렬 및 오버레이 배치 안정화
- 단축키 기능당 2개 슬롯 지원 및 기본 단축키 개선
- Ctrl+Z 복구 구조 안정화 및 관계없는 오버레이 이동 문제 수정
- 프로그램 자석 자동 연결 기본 OFF 및 잘못된 창 재연결 방지
- 웹/이미지/GIF/오버레이 렌더링 및 드래그 성능 최적화
- 회전/원본 크기 복원/레이어드 이미지 크기 갱신 안정화
- Ctrl+C 동작을 오버레이 복제에서 '선택 이미지 원본 복사'로 변경
- 오버레이 복제는 우클릭 메뉴의 '오버레이 복제'로 유지

정리
- 개발 중 사용한 상세 진단/드래그/오류 파일 로그 시스템 제거
- CLIP STUDIO PAINT 색상 연동 실험 기능 제거
- 테스트 전용 파일과 메뉴 제거

추가 안정화
- 새 메인 화면 파일 추가 클릭 범위를 톱니 버튼을 제외한 화면 대부분으로 확장
- 전역 단축키를 키 통과형 방식으로 변경
  (CatLayer 기능 실행과 동시에 게임/다른 프로그램도 같은 키를 받음)
- 릴리스 빌드 컴파일 경고 원인 정리
