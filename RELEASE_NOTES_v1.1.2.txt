CatLayer v1.1.2 업데이트

- 크기 조절 안정화
  - 8방향 크기 조절과 리사이즈 판정 유예 지원
  - 크기 확대 중 발생하던 선택 테두리의 검은 프레임 현상 수정

- 이미지 회전 개선
  - 이미지 표시 크기는 유지하고 회전에 필요한 투명 캔버스만 확장
  - 회전 전 X/Y 위치를 기준으로 위치 유지

- 웹 오버레이 개선
  - 크기 조절 중 파란 테두리로 미리보기 후 마우스를 놓을 때 실제 웹 크기 적용
  - 새 창/새 탭, 다운로드, 권한 요청 및 위험한 특수 프로토콜 차단
  - 로컬 CatLayerWeb 경로 접근 제한 보강

- 기본 CatLayerWeb 5종 포함
  - 체크리스트
  - 그림판
  - 타이머보드
  - 메모장
  - 미니계산기

- 로그 정리
  - 테스트용 크기 조절 진단 로그 제거
  - 오류/업데이트 로그가 무한히 커지지 않도록 용량 제한
