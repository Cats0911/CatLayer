CatLayer v1.2.1
================

CatLayer는 Windows 화면 위에 이미지/GIF, 텍스트, 타이머, OBS Program 화면,
웹페이지와 CatLayerWeb 위젯을 원하는 위치에 띄우고 관리하는 오버레이 도구입니다.

Copyright © 2026 과출. All rights reserved.

[권장 설치]
1. ZIP 파일 전체를 일반 폴더에 압축 해제합니다.
2. INSTALL.bat을 실행합니다.
3. 설치 위치: %LOCALAPPDATA%\CatLayer\App
4. 설치 후 Windows 설정 > 설치된 앱 또는 제어판 > 프로그램 제거에 CatLayer가 표시됩니다.
5. 바탕화면과 시작 메뉴에 CatLayer 바로가기가 생성됩니다.

첫 설치 시 WebView2 SDK 파일이 없으면 Microsoft NuGet에서 고정 버전 SDK를 한 번 내려받아 빌드합니다.
웹 오버레이 사용에는 Microsoft Edge WebView2 Runtime이 필요합니다.

[휴대/직접 실행]
- Visual Studio 프로젝트는 필요하지 않습니다.

[주요 기능]
- 이미지 / GIF / WebP / 텍스트 / 타이머 / OBS Program / 웹 오버레이
- HTTP/HTTPS 주소, 로컬 HTML, .catlayerweb 웹 위젯 지원
- 파일/URL 드래그앤드롭 및 이미지 클립보드 붙여넣기
- Ctrl+C로 선택 이미지 원본 복사, 우클릭 메뉴로 오버레이 복제
- Chromium/Firefox 브라우저 및 Pinterest 이미지 드래그 처리 강화
- 자동 이미지 최적화, GIF 재생/프레임 제어
- 비정상 종료 자동 저장/복구, 부모/자식 Hierarchy
- 화면 영역 캡처 후 즉시 이미지 오버레이 생성
- 위치/크기/투명도/레이어 순서 조절
- 개별 표시/숨김, 전체 표시/숨김, 빠른 숨김/복원
- 그룹 만들기/해제/이동 및 .catlayergroup 공유
- 프리셋 저장/불러오기/삭제/외부 가져오기
- 자유 회전, 좌우/상하 반전, 이미지 자르기
- 배치 자석 / 회전 자석 / 프로그램 창 자석
- 리모컨에서 오버레이 목록 및 주요 기능 제어
- 사용자 지정 전역/편집 단축키
- 트레이 백그라운드 실행 및 자동 업데이트 확인

[고정 / 편집]
- 고정: 오버레이가 클릭을 통과하는 실제 사용 상태입니다.
- 편집: 오버레이 이동, 크기 조절, 그룹, 회전, 반전, 자르기 등을 사용합니다.
- F8 기본 단축키로 고정 ↔ 편집을 전환합니다.

[웹 조작 방식]
메뉴 > 설정 > 웹 조작 방식에서 하나를 선택합니다.

1. 더블클릭
   - 편집 상태에서 웹 오버레이를 더블클릭하면 웹 조작 모드로 들어갑니다.

2. 원클릭
   - 웹을 실제 클릭했을 때 웹 조작 모드로 들어갑니다.
   - 드래그로 오버레이를 옮기는 동작과 단순 클릭을 구분합니다.

3. 통합
   - 일반 오버레이는 편집하면서 웹 내부는 바로 클릭/스크롤/키보드 입력할 수 있습니다.
   - 웹 위치/크기는 선택 테두리를 사용합니다.

F10 기본 단축키로 웹 조작 모드를 직접 켜고 끌 수도 있습니다.
웹 조작 모드에서는 Ctrl+휠로 웹페이지 확대/축소가 가능합니다.

[프로그램 자석]
- 오버레이를 다른 프로그램 창의 바깥쪽 또는 안쪽 가장자리에 붙일 수 있습니다.
- 붙은 뒤 대상 프로그램 창을 이동하거나 크기를 바꾸면 오버레이가 해당 면을 따라갑니다.
- 메뉴 > 설정 > 프로그램 자석 감도... 에서 자동 부착 거리를 0~100px로 조절합니다.
- 기본값 36px, 0px은 자동 프로그램 자석 끄기입니다.
- 오버레이 우클릭 메뉴에서 수동 프로그램 자석도 사용할 수 있습니다.

[리모컨]
- 메인 화면, 오버레이 우클릭, 트레이 우클릭에서 리모컨을 열 수 있습니다.
- 파일 또는 링크를 리모컨으로 드래그해 오버레이를 추가할 수 있습니다.
- 현재 오버레이 목록을 확인하고 항목을 선택할 수 있습니다.
- 편집/고정, 전체 표시/숨김, 빠른 숨김, 숨김 취소, 선택 표시,
  웹 새로고침, 프리셋, 그룹 불러오기를 사용할 수 있습니다.
- 리모컨 창은 크기 조절이 가능합니다.

[빠른 숨김]
- F9: 직접 클릭한 오버레이를 우선 숨기고, 대상이 없으면 목록 위의 표시 중 항목부터 하나씩 숨깁니다.
- Shift+F9: 최근 빠른 숨김 항목부터 하나씩 다시 표시합니다.
- F11: 모든 오버레이 전체 숨김 ↔ 전체 표시입니다.
- 빠른 숨김과 전체 숨김은 서로 별도 기능입니다.

[우클릭]
- 짧게 우클릭: 기존 오버레이 메뉴를 엽니다.
- 우클릭한 채 드래그: 편집 상태에서 오버레이를 이동합니다.
- 웹 오버레이에서도 우클릭 드래그 이동을 사용할 수 있습니다.

[기본 단축키]
- Ctrl+Shift+X : 화면 영역 캡처
- F8           : 고정 ↔ 편집
- F9           : 빠른 숨김
- Shift+F9     : 빠른 표시
- F10          : 웹 조작 모드
- F11          : 전체 표시/숨김
- Ctrl+C       : 선택 오버레이 복사 (OBS 제외)
- Ctrl+V       : 클립보드 정적 이미지 붙여넣기
- Ctrl+G       : 그룹화/그룹해제
- Ctrl+Shift+G : 그룹 해제
- Q / E        : 회전 -1° / +1°
- Shift+Q/E    : 회전 -10° / +10°
- H / V        : 좌우 / 상하 반전
- R            : 회전 각도 0°
- Shift+R      : 회전/반전 전체 초기화
- 방향키       : 1px 이동
- Shift+방향키 : 10px 이동
- Delete       : 선택 오버레이 삭제
- Ctrl+Z       : 실행 취소

메뉴 > 설정 > 사용자 지정 단축키에서 주요 전역/편집 단축키를 변경할 수 있습니다.
리모컨 열기 / 선택 웹 새로고침 / 프리셋 불러오기 / 그룹 불러오기는 기본값이 지정 안 함이며 필요할 때 직접 지정할 수 있습니다.
Ctrl+C / Ctrl+V는 CatLayer 예약키입니다.

[CatLayerWeb]
- .catlayerweb은 HTML/CSS/JavaScript와 허용된 리소스를 하나로 묶어 사용하는 CatLayer 웹 위젯 형식입니다.
- examples 폴더에 기본 위젯 예제가 포함되어 있습니다.
- .catlayerweb을 CatLayer 또는 리모컨으로 드래그하거나, 설치판에서 더블클릭해 열 수 있습니다.
- 로컬 웹은 실행 파일 계열을 포함하지 않으며 다운로드/권한 요청과 네이티브 브리지를 제한합니다.

[그룹 파일]
- 그룹 또는 2개 이상 선택 항목을 .catlayergroup 파일로 저장할 수 있습니다.
- 필요한 이미지/GIF/타이머 알람/웹 정보 등을 포함해 다른 PC로 공유할 수 있습니다.
- CatLayer 또는 리모컨으로 드래그하거나 설치판에서 더블클릭해 불러올 수 있습니다.

[OBS Bridge]
1. OBS 실행
2. OBS > 도구 > 스크립트
3. + 버튼
4. obs\CatLayer_OBS_Bridge.lua 추가
5. CatLayer에서 OBS 화면 추가

CatLayer는 OBS Program Windowed Projector + DWM Thumbnail 방식을 사용합니다.

[설정 및 사용자 데이터]
%LOCALAPPDATA%\CatLayer\
  config.txt
  config.txt.bak
  Assets\
  Sounds\
  Presets\
  Undo\
  WebData\
  WebFiles\
  crash.log

설정 로드 실패 시 config.txt.bak 자동 복구를 시도합니다.

[제거]
- Windows 설정 > 설치된 앱 / 제어판 > 프로그램 제거
- 또는 %LOCALAPPDATA%\CatLayer\App\Uninstall.exe
- 프로그램만 제거하거나 사용자 데이터까지 완전 삭제할 수 있습니다.

[버전]
VERSION.txt가 프로그램/설치/제거/업데이트에서 사용하는 버전 정보의 기준 파일입니다.

[GitHub 자동 업데이트용 배포 파일 만들기]
개발자가 GitHub Release용 자동 업데이트 파일을 만들 때는 CatLayer_Data\tools\BUILD_RELEASE.bat을 실행합니다.
Windows에서 CatLayer_Data\tools\BUILD_RELEASE.bat을 실행하면 release 폴더에 아래 두 파일이 생성됩니다.
- CatLayer_v버전_update.zip
- SHA256.txt

GitHub의 Cats0911/CatLayer 저장소에서 태그를 v버전 형식으로 정식 Release(Published)하고, 위 두 파일을 Assets에 함께 올리면 됩니다.
Draft 또는 Pre-release는 자동 업데이트 대상이 아닙니다.
일반 설치용 CatLayer_v버전.zip은 별도로 함께 올려도 됩니다.
