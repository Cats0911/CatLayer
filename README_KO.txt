CatLayer v1.1.0 개발판 - 테두리 시스템 개편

[v1.1.0 개발 진행 사항]
- 실제 표시 영역 기준 테두리/자석 시스템을 계속 사용합니다.
- WebView2 기반 웹 오버레이 1차 개발 기능을 추가했습니다.
- 웹 오버레이는 HTTP/HTTPS 주소를 입력해 생성합니다.
- 편집 모드에서 웹페이지를 직접 클릭해 스크롤/입력/링크 조작이 가능합니다.
- 웹 오버레이 이동은 선택 테두리를 드래그하고, 우하단 사각형으로 크기를 조절합니다.
- 고정 모드에서는 웹 오버레이 입력을 비활성화하고 기존 오버레이처럼 클릭 통과하도록 구성했습니다.
- 웹 투명도 기능은 이번 단계에서는 제외했습니다.
- 웹 쿠키/캐시/로그인 데이터는 %LOCALAPPDATA%\CatLayer\WebData 에 저장하고 모든 웹 오버레이가 같은 WebView2 환경을 공유합니다.
- 웹 오버레이가 없는 경우 WebView2 브라우저 환경을 초기화하지 않습니다.
- 웹 오버레이가 포함된 프리셋은 V7로 저장하며, 웹 오버레이가 없는 프리셋은 기존 V6 저장을 유지합니다.
- GitHub 업데이트 기능과 전체 RAM/CPU 최적화는 다음 개발 단계에서 진행합니다.

CatLayer는 Windows 화면 위에 이미지/GIF, 텍스트, 타이머, OBS Program 화면, 웹페이지를
띄우고 자유롭게 배치할 수 있는 범용 오버레이 도구입니다.

[권장 설치]
1. ZIP 파일 전체를 일반 폴더에 압축 해제합니다.
2. INSTALL.bat을 실행합니다.
3. 설치 위치: %LOCALAPPDATA%\CatLayer\App
4. 설치 후 Windows 설정 > 설치된 앱 및 제어판 > 프로그램 제거에 CatLayer가 표시됩니다.
5. 바탕화면/시작 메뉴에 CatLayer 바로가기가 생성됩니다.

[휴대/직접 실행]
- RUN.bat을 실행하면 현재 소스를 Windows 기본 .NET Framework 4.x csc.exe로 빌드한 뒤 실행합니다.
- Visual Studio 프로젝트는 필요하지 않습니다.
- RUN.bat은 매번 현재 소스를 새로 빌드합니다.

- 이미지 / GIF / 텍스트 / 타이머 / OBS Program 화면 / 웹페이지 오버레이
- PNG/JPG/JPEG/BMP/GIF 탐색기 드래그앤드롭
- 브라우저 정적 이미지 Ctrl+V / 웹 이미지 드래그
- 화면 영역 캡처 후 즉시 이미지 오버레이 생성
- 항상 위 표시, 위치/크기/투명도/레이어 순서 조절
- 목록 드래그로 레이어 순서 변경
- 개별 표시/숨김, 위치/크기 잠금, 사용자 지정 이름
- 그룹 만들기/해제/이동/확대·축소
- 자유 회전, 좌우/상하 반전, 회전/반전 초기화
- 회전 자석 및 배치 자석
- 프리셋 저장/불러오기/삭제/외부 가져오기 및 프리셋 단축키
- 실행 취소, 전체 삭제, 설정 초기화, 전체 숨김
- 트레이 백그라운드 실행 및 중복 실행 시 기존 창 복귀
- 모니터 변경 시 화면 밖 오버레이 자동 복구

[편집 모드]
CatLayer v1.0.5부터 편집 모드는 2단계로 단순화되었습니다.

1. 고정 모드
   - 오버레이 클릭 통과
   - 실제 게임/그림/방송/업무 사용 상태

2. 편집 모드
   - 이동, 크기 조절, 다중 선택, 그룹, 회전, 반전, 정밀 이동, 휠 확대/축소를 모두 사용
   - 선택된 오버레이만 편집 테두리 표시
   - CatLayer가 아닌 다른 프로그램을 클릭하면 편집 테두리만 숨기고 선택 상태는 유지

[기본 단축키]
- F1: 화면 영역 캡처
- F8: 고정 ↔ 편집 모드
- F9: 전체 표시 / 숨김
- Ctrl+C: 선택 오버레이 즉시 복사/복제 (OBS 제외)
- Ctrl+V: 클립보드 정적 이미지 붙여넣기
- Ctrl+G: 그룹화/그룹해제
- Ctrl+Shift+G: 그룹 해제
- Q / E: 회전 -1° / +1°
- Shift+Q / Shift+E: 회전 -10° / +10°
- H / V: 좌우 / 상하 반전
- R: 회전 각도 0° (반전 유지)
- Shift+R: 회전/반전 전체 초기화
- 방향키: 1px 이동
- Shift+방향키: 10px 이동
- Delete: 선택 오버레이 삭제

F1/F8/F9 및 편집 단축키는 메뉴 > 설정 > 사용자 지정 단축키에서 변경할 수 있습니다.
Ctrl+C / Ctrl+V는 CatLayer 예약키입니다.

[이미지 자르기]
- 편집 모드에서 이미지의 크기 조절 테두리를 Shift를 누른 채 드래그하면 이미지가 잘립니다.
- 오버레이 몸통에서 Shift+클릭하는 기존 다중 선택 기능은 그대로 유지됩니다.
- 자르기 상태는 설정, 프리셋, Undo, 오버레이 복사에 저장됩니다.

[배치 자석]
- 오버레이를 이동할 때 화면 가장자리/중앙 또는 다른 오버레이의 선 가까이에서 자동 정렬됩니다.
- 메뉴 > 설정 > 배치 자석 감도... 에서 0~30px로 조절합니다.
- 기본값 8px, 0px는 비활성화입니다.

[회전]
- 편집 모드에서 Ctrl+좌클릭 드래그: 자유 회전
- Ctrl+휠: 그룹 단위 확대/축소
- Ctrl+Shift+휠: 개별 확대/축소
- 회전 자석 감도는 메뉴 > 설정 > 회전 자석 감도... 에서 0~15°로 조절합니다.
- 이미지 오버레이 우클릭에서 좌우 반전 / 상하 반전을 바로 전환할 수 있습니다.
- 이미지 우클릭 > 각도 초기화 (반전 유지): 각도만 0°로 초기화하고 반전 상태는 유지합니다.
- 이미지 우클릭 > 회전/반전 전체 초기화: 각도와 좌우/상하 반전을 모두 초기화합니다.
- 우클릭 변형 작업은 Ctrl+Z로 실행 취소할 수 있습니다.
- OBS DWM Thumbnail은 자유 회전/반전을 지원하지 않습니다.

[화면 영역 캡처]
- 기본 F1 또는 메인 화면의 영역 캡처 버튼을 사용합니다.
- CatLayer 창/오버레이가 잠시 숨겨지고 원하는 화면 영역을 드래그합니다.
- 선택한 부분만 PNG 이미지 오버레이로 생성됩니다.
- ESC로 취소할 수 있으며 멀티모니터를 지원합니다.

[화면 밖 오버레이 자동 복구]
- 저장된 위치가 현재 연결된 모니터에서 완전히 벗어나 있으면 실행 시 자동으로 현재 화면 안으로 복구합니다.
- 프로그램 실행 중 모니터 연결/해제 또는 디스플레이 구성이 바뀌어도 자동 복구를 시도합니다.

[프리셋]
- 웹 오버레이가 없는 프리셋은 기존 V6 포맷으로 저장합니다.
- 웹 오버레이가 포함된 프리셋은 V7 포맷으로 저장합니다.
- 기존 V1~V6 프리셋 불러오기 호환을 유지합니다.
- 웹 로그인/쿠키/캐시는 프리셋에 포함하지 않습니다.

[웹 오버레이]
- 메인 화면의 웹 버튼에서 HTTP/HTTPS 주소를 입력해 추가합니다.
- 편집 모드: 웹 내용을 직접 클릭해 스크롤, 키보드 입력, 링크 이동 등을 사용할 수 있습니다.
- 이동: 선택된 웹 오버레이의 파란 테두리를 드래그합니다.
- 크기 조절: 테두리 우하단 사각형을 드래그합니다.
- 목록 우클릭 > 웹 도구에서 주소 변경 / 새로고침 / 뒤로 / 앞으로를 사용할 수 있습니다.
- 웹 투명도는 현재 100% 고정입니다.
- WebView2 브라우저 데이터는 %LOCALAPPDATA%\CatLayer\WebData 에 저장됩니다.
- 로그인 쿠키와 캐시는 프리셋 파일에 포함되지 않습니다. 프리셋에는 웹 주소와 오버레이 배치 정보만 저장됩니다.
- 첫 개발 빌드 시 WebView2 SDK가 없으면 INSTALL.bat이 Microsoft NuGet에서 고정 버전 SDK를 한 번 내려받아 빌드에 사용합니다.
- 실행 PC에는 Microsoft Edge WebView2 Runtime이 필요합니다. Runtime이 없으면 웹 오버레이에 오류 안내가 표시됩니다.

[OBS Bridge]
1. OBS 실행
2. OBS > 도구 > 스크립트
3. + 버튼
4. obs\CatLayer_OBS_Bridge.lua 추가
5. CatLayer에서 OBS 화면 추가

CatLayer는 OBS Program Windowed Projector + DWM Thumbnail 방식을 사용합니다.
OBS 검색은 제한된 횟수만 수행하며 연결 실패 시 무한 검색하지 않습니다.

[기존 LightOverlay 사용자]
- 기존 %LOCALAPPDATA%\LightOverlay 사용자 데이터가 있으면 CatLayer로 필요한 항목을 복사 이전합니다.
- 기존 LightOverlay 원본 데이터는 자동 삭제하지 않습니다.

[제거]

- 또는 %LOCALAPPDATA%\CatLayer\App\Uninstall.exe
- 프로그램만 제거: 설정/프리셋/사용자 데이터 유지
- 완전 삭제: CatLayer 프로그램과 사용자 데이터까지 제거

[v1.1.0 웹 조작 모드]
- F10: 웹 조작 모드 진입/종료 (기본값)
- 웹 조작 모드에서는 웹페이지 클릭, 스크롤, 키보드 입력만 사용하며 일반 오버레이 편집 기능은 잠시 비활성화됩니다.
- 편집 모드 Ctrl+휠: 기존 오버레이 크기 조절
- 웹 조작 모드 Ctrl+휠: WebView2 웹페이지 확대/축소
- 웹 오버레이 우클릭: 웹 투명도 / 커스텀 CSS / 주소 변경 / 새로고침
- 웹 투명도와 커스텀 CSS는 설정 및 웹 프리셋에 저장됩니다.
- WebView2 데이터는 %LOCALAPPDATA%\CatLayer\WebData 에 저장됩니다.
- 캡처/웹 추가 버튼에 전용 아이콘이 추가되었습니다.

[v1.1.0 그룹 파일 / WebP 개발 기능]
- 이미지 선택에서 .webp 확장자를 지원합니다.
- .webp 파일은 System.Drawing으로 먼저 열고, 필요하면 Windows Imaging Component(WIC) 디코더를 사용합니다.
- 작은 '영역 캡처' / '웹' 버튼은 아이콘이 글자와 겹치지 않도록 세로 배치로 조정했습니다.
- 그룹 또는 2개 이상 다중 선택 항목을 .catlayergroup 파일로 저장할 수 있습니다.
- .catlayergroup 파일은 이미지/GIF, 텍스트, 타이머 알람, 웹 URL/CSS/줌 등 필요한 데이터를 파일 안에 포함하므로 다른 사용자에게 공유할 수 있습니다.
- 그룹 파일을 불러오면 기존 오버레이를 지우지 않고 새 그룹 ID로 추가합니다.
- 그룹 파일은 메뉴/목록 우클릭에서 불러올 수 있고, CatLayer 창으로 드래그하거나 설치판에서 더블클릭해도 추가됩니다.

[1.1.0 개발 기능 - 로컬 웹 보안]
- 로컬 .html/.htm은 원본 위치를 직접 file://로 열지 않고 %LOCALAPPDATA%\CatLayer\WebFiles 아래로 안전한 웹 리소스만 복사한 뒤 WebView2 가상 호스트 매핑으로 표시합니다.
- 허용된 로컬 웹 리소스만 복사되며 EXE/BAT/CMD/PS1/MSI/DLL 같은 실행 파일은 포함하지 않습니다.
- 로컬 HTML에서는 object/embed/applet/frame/frameset 및 meta refresh 요소를 제거합니다. JavaScript/CSS/이미지/폰트/미디어는 위젯 용도로 계속 사용할 수 있습니다.
- WebView2의 네이티브 HostObject/WebMessage 브리지는 열지 않으며, 카메라/마이크/위치 등 권한 요청과 다운로드를 기본 차단합니다.
- 최상위 이동은 HTTP/HTTPS/about만 허용합니다.

[1.1.0 개발 기능 - CatLayerWeb]
- 웹 추가 버튼에서 URL뿐 아니라 .html/.htm/.catlayerweb 파일을 직접 선택할 수 있습니다.
- 로컬 HTML 웹 오버레이를 우클릭하여 "CatLayerWeb 파일로 저장..."을 선택하면 HTML/CSS/JS/이미지 등 허용된 웹 리소스를 하나의 .catlayerweb 파일로 묶을 수 있습니다.
- .catlayerweb 파일은 CatLayer 창에 드래그하거나 설치판에서 더블클릭하여 웹 오버레이로 추가할 수 있습니다.
- 패키지 내부 파일은 WebFiles 전용 폴더로 풀리며, 실행 파일 계열은 허용하지 않습니다.
- examples\CatLayerWeb_투명시계_샘플.catlayerweb 파일로 로컬 HTML/CSS/JS 동작을 바로 테스트할 수 있습니다.
- F10 웹 조작 모드 종료 시 진입 전 편집/고정 모드로 복귀하며, 웹 오버레이만 입력 가능하도록 창 스타일을 분리합니다.
