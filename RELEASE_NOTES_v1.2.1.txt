CatLayer v1.2.1

이번 버전은 대형 신규 기능보다 조작감, 사용 편의성, 안정성 정리에 집중했습니다.

주요 변경 사항
- 새 메인화면 조작감 개선
- 오버레이 선택 시 미니 조작바 추가
- 미니 조작바 깜빡임 및 설정/메뉴 포커스 문제 수정
- 삭제 후 되돌리기 안내 추가
- 파일 드래그 시 추가 위치 안내
- 쉬운 설정 / 고급 설정 분리
- 화면 상태 복구 기능 추가
- 첫 실행 자동 가이드 제거
- 신화면 톱니 메뉴에 CatLayer 제거 기능 추가
- Pinterest 전용 열기 바로가기 제거
- Pinterest/Chromium 이미지 드래그 기능 유지
- 기존 기본 단축키 체계 복원
- 오버레이별 항상 위(TopMost) ON/OFF 추가

기본 단축키
- 편집/고정: Alt+Q / F8
- 빠른 숨김: Alt+W / F9
- 빠른 표시: Alt+Shift+W / Shift+F9
- 영역 캡처: Alt+E / F7
- 전체 표시/숨김: F11
- 웹 조작: F10

TopMost
- 오버레이 우클릭 메뉴의 '항상 위 (TopMost)'에서 개별 오버레이의 항상 위 동작을 끌 수 있습니다.
- 기본값은 기존과 동일하게 ON입니다.

설치
- ZIP 압축 해제 후 INSTALL.bat 실행
